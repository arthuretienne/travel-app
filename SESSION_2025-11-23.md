## 🔧 Problèmes identifiés

### 1. Bug "0 recommandations" ❌
**Description:** Le workflow s'arrêtait complètement quand Amadeus ne trouvait aucun vol.

**Logs utilisateur:**
```
✅ Generated 10 destinations
✅ Pre-screened to 0 destinations
⚠️  Only 0 results after filtering - relaxing budget constraint to guarantee 3 results
✅ Returning 0 budget-appropriate recommendations (guaranteed minimum 3)
```

**Problème:** Contradiction entre "guaranteed minimum 3" et 0 résultats retournés.

**Cause racine:**
- Amadeus pre-screening retourne 0 vols disponibles
- Workflow s'arrête → aucune recommandation

**Philosophie utilisateur:**
> "Il ne devrait presque jamais y avoir de 0 recommandations car : d'abord tu check avion, ensuite si trop cher bus si jamais c'est galère hotel activités etc il faut pouvoir proposer auto stop tente activités gratuite etc..."

### 1. Workflow avec fallbacks multi-niveaux

**Fichier:** [`backend/src/routes/travel.js`](backend/src/routes/travel.js)

#### A. Fallback si pré-screening = 0 résultats
```javascript
// CRITICAL FALLBACK: If no destinations have flights, keep ALL destinations
if (preScreened.length === 0) {
  console.warn('⚠️  Pre-screening returned 0 results - keeping ALL destinations for fallback transport search');
  preScreened = destinations.slice(0, 10); // Keep all 10 Claude destinations
} else if (preScreened.length < 3) {
  // If less than 3, add more from original list to ensure variety
  const remaining = destinations.filter(d => !preScreened.find(p => p.iataCode === d.iataCode));
  preScreened = [...preScreened, ...remaining].slice(0, 10);
}
```

#### B. Coût transport estimé si aucun vol
```javascript
// FALLBACK: If no flight found, create estimated transport cost
if (!flightOffer) {
  console.log(`⚠️  No flights found for ${destination.city} - using estimated transport cost`);

  // Estimate transport cost based on distance/budget
  const estimatedFlightCost = destination.estimatedBudget
    ? Math.round(destination.estimatedBudget * 0.4) // 40% of estimated budget for transport
    : Math.round(userProfile.basic.budget * 0.3); // Or 30% of user budget

  // Create a placeholder flight offer with estimated cost
  flightOffer = {
    price: estimatedFlightCost,
    segments: [],
    totalDuration: 'Unknown',
    validatingAirline: 'TBD',
    cabinClass: 'ECONOMY',
    isEstimate: true, // Flag to indicate this is not real flight data
    transportNote: 'Vol non disponible - coût estimé (train/bus possible)'
  };
}
```

#### C. Garantie minimum 3 résultats
```javascript
// CRITICAL GUARANTEE: Always return at least 3 results
// If budget/quality filtering removed too many, relax constraints
if (qualityFiltered.length < 3 && validResults.length >= 3) {
  console.warn(`⚠️  Only ${qualityFiltered.length} results after filtering - relaxing budget constraint to guarantee 3 results`);
  // Take top 3 by score from unfiltered results
  validResults.sort((a, b) => b.score.total - a.score.total);
  validResults = validResults.slice(0, 3);
} else {
  validResults = qualityFiltered;
}
```

**Impact:** Le système retourne TOUJOURS au moins 3 recommandations, même sans vols disponibles.

MANDATORY FLIGHT CONNECTIVITY RULES:

#### B. Fonctions de recherche
```javascript
export function searchAirports(query) {
  if (!query || query.length < 2) return [];

  const lowerQuery = query.toLowerCase();

  return AIRPORTS
    .filter(airport =>
      airport.city.toLowerCase().includes(lowerQuery) ||
      airport.name.toLowerCase().includes(lowerQuery) ||
      airport.code.toLowerCase().includes(lowerQuery) ||
      airport.country.toLowerCase().includes(lowerQuery)
    )
    .slice(0, 10); // Limit to 10 results
}

export function getPrimaryAirport(cityName) {
  const airports = AIRPORTS.filter(a => a.city.toLowerCase() === cityName.toLowerCase());
  const primary = airports.find(a => a.primary);
  return primary || airports[0] || null;
}

export function getAirportDisplayName(airport) {
  if (airport.city === airport.name) {
    return `${airport.city} (${airport.code})`;
  }
  return `${airport.city} - ${airport.name} (${airport.code})`;
}
```

**Recherche intelligente:**
- Recherche par ville, nom, code IATA, pays
- Minimum 2 caractères
- Limite 10 résultats
- Priorité aux aéroports principaux

## 💡 Décisions techniques importantes

### 1. Data flow aéroports
**Décision:** Frontend stocke des objets, transforme en codes IATA avant API

**Raison:**
- UX riche (afficher nom complet, pays, badge "Principal")
- Backend simple (reçoit juste `["CDG", "LYS"]`)
- Validation côté frontend (doublons, limite max)

**Alternative rejetée:** Backend gère les objets → complexité inutile

---

### 2. Stratégie de fallback
**Décision:** Multi-niveaux (Amadeus → FlixBus → Estimation → Min 3 garantis)

**Raison:**
- Philosophie utilisateur: "jamais 0 recommandations"
- Dégradation gracieuse plutôt que erreur
- Permet d'afficher coût estimé avec disclaimer

**Alternative rejetée:** Retourner erreur si pas de vols → mauvaise UX

---

### 3. Origine dans le prompt
**Décision:** Passer `originCity` dynamiquement à Claude (pas hardcodé)

**Raison:**
- Claude génère destinations pertinentes selon origine réelle
- Suggestions de transport alternatif (train, bus) adaptées
- Meilleure précision des estimations de budget

**Alternative rejetée:** Origine dans le profil user uniquement → Claude ignore

---

### 4. Priorité aéroports
**Décision:** `userPreferences.preferredAirports[0]` > `availability.originCity` > `'CDG'`

**Raison:**
- Préférences explicites utilisateur prioritaires
- Fallback sur origine déclarée dans formulaire
- Default CDG si rien de renseigné (Paris = hub principal)
